# 오늘 뭐먹지 (맛집 지도)

세종대 주변 맛집을 지도에서 찾아보는 웹 프로젝트입니다.
민 / 지 / 원 세 사람이 각각 만든 프로토타입을 하나로 통합한 버전입니다.

## 폴더 구조

```
food-map/
├── index.html              # 화면 구조
├── CSS/
│   └── style.css           # 전체 스타일
├── JS/
│   ├── main.js             # 동작 스크립트
│   ├── config.example.js   # 지도 키 설정 예시 (저장소에 포함)
│   └── config.local.js     # 실제 지도 키 (각자 만듦, 저장소에 안 올라감)
├── README.md
└── .gitignore
```

## 실행 방법

별도 빌드나 설치는 필요 없지만, 지도를 띄우려면 아래 순서대로 준비해야 합니다.

1. `JS/config.example.js`를 같은 폴더에 복사해서 `config.local.js`로 이름을 바꿉니다.
2. `config.local.js` 안의 `"여기에_Client_ID"`를 네이버 클라우드 Maps의 Client ID로 바꿉니다.
3. VS Code Live Server 확장으로 `index.html`을 엽니다.

`file://`로 직접 열면 네이버 지도 인증이 되지 않으므로 Live Server로 열어야 합니다.
지도가 안 뜨면 브라우저 개발자도구(F12) 콘솔에 원인 메시지가 표시됩니다.

## 네이버 지도 설정

- 네이버 클라우드 플랫폼 콘솔에서 Application을 등록하고 **Web Dynamic Map**을 선택합니다.
- Web 서비스 URL에는 `http://127.0.0.1`, `http://localhost`를 등록합니다. 포트 번호(`:5500` 등)는 넣지 않습니다.
- 배포하게 되면 배포 도메인도 서비스 URL에 추가해야 합니다.
- 지도 스크립트 파라미터는 `ncpKeyId`입니다. 예전 자료에 나오는 `ncpClientId`는 쓰지 않습니다.

### 키 관리 규칙

- `config.local.js`는 `.gitignore`에 등록되어 있어 저장소에 올라가지 않습니다. 팀원은 각자 만들어야 합니다.
- 웹 지도용 Client ID는 브라우저에 노출되는 값이며, 콘솔에 등록한 서비스 URL로 사용이 제한됩니다.
- **Client Secret은 프런트 코드 어디에도 넣지 않습니다.** 주소 검색(Geocoding), 길찾기(Directions) 같은 REST API는 Secret이 필요하므로 백엔드를 거쳐 호출해야 합니다.
- GitHub Pages처럼 저장소에서 바로 배포하면 `config.local.js`가 없어 지도가 뜨지 않습니다. 배포 방식이 정해지면 키 넣는 방법을 따로 정해야 합니다.

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| 왼쪽 사이드바 | 메뉴 바 버튼 + 기능 아이콘 5종, 하단에 북마크 / MY / 설정 고정 |
| 상단 검색창 | 지도 위에 떠 있는 알약형 검색창 (패널과 분리되어 항상 표시) |
| 검색 패널 | 음식 종류 필터 + 결과 목록, 좌우 슬라이드로 열고 닫힘 |
| 지도 영역 | 네이버 지도 (세종대 부근 중심, 지도를 클릭하면 패널이 닫힘 / 드래그는 제외) |

## 통합 기준

각 파일에서 가져온 부분입니다.

- **원** — 사이드바 메뉴 구성과 아이콘 배치 순서, 검색창 크기(340 × 50), 패널 너비(400px)
- **민** — 사이드바 아이콘 SVG, 검색창 디자인(알약형 + 그림자), 지도 클릭 시 패널 닫기
- **지** — 패널 슬라이드 개폐와 오른쪽 중앙 토글 버튼, 패널 그림자, 음식 종류 필터 버튼

'오먹' 로고는 빼고 그 자리에 메뉴 바 버튼을 넣었습니다.
추천 랭킹(시상대)과 숨.맛.공(지도 핀) 아이콘은 기존 파일에 없어서 새로 만들었습니다.

## 작업 규칙

- 색상과 치수는 `css/style.css` 맨 위 `:root` 변수에서 관리합니다. 값을 바꿀 때는 여기부터 확인해 주세요.
- 새 화면을 추가할 때는 `main.js`의 `panelContents` 연결표에 `data-panel` 값과 함수를 함께 등록합니다.
- 지도 객체는 `main.js`의 전역 변수 `map`에 들어 있습니다. 마커 등 지도 기능은 지도가 준비된 뒤(`initMap` 이후)에 사용해야 합니다.
- 폴더 이름은 대문자(`CSS/`, `JS/`)입니다. 배포 서버에 따라 대소문자를 구분하므로 경로를 쓸 때 주의합니다.
